# Edwin Digital Dashboard V2

Panel multiempresa para analizar páginas web y, opcionalmente, ventas de plataformas integradas. Cloudflare Workers + Supabase + Google Analytics 4 Data API; piloto de Hotmart limitado al administrador.

**Configuración de producción:** leer `GUIA-DE-ACTUALIZACION.md`. Nunca subir secretos a GitHub.

Archivos: `worker.js`, `wrangler.jsonc`, `package.json`, `public/index.html`, `public/style.css`, `public/app.js`.
