# Edwin CRM · 50 acciones de mejora y control de lanzamiento

**Fecha:** 5 de noviembre de 2026. **Alcance:** acciones A01–A50 de este lote, distintas de las capacidades C01–C50 del plan anterior.

Las 50 acciones incluyen **funciones visibles, correcciones de seguridad y verificaciones automatizadas**. No equivalen a 50 nuevos módulos ni a 50 suscripciones conseguidas. Cada fila corresponde a un caso comprobable en código o pruebas. Las acciones pendientes de CI no se cuentan como publicadas.

**Límite de alcance:** los controles estáticos no comprueban aislamiento de usuarios reales, Cloudflare Production, OAuth de terceros, envíos de correo, pagos, renovación de suscripciones ni cumplimiento legal. Estas verificaciones siguen en `docs/PRELANZAMIENTO-PILOTO-CRM.md`. Ninguna fila autoriza publicidad, cobros o datos externos sin pruebas reales.

## Protocolo de actualización

Antes de dar por publicada una acción: confirmar pruebas y checks aplicables en el commit del PR, fusión segura en `main` y anotar el PR. Una compilación de Workers sin una prueba del dominio no demuestra que el entorno de producción haya desplegado el mismo commit.
